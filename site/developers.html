For developers

SpikeClip SDK

Teach SpikeClip your game. Write a small Python plugin that finds, understands or rates the moments in a video. SpikeClip does the rest.

Your plugin knows what a great moment looks like in your game. SpikeClip downloads the video, writes down what is said, and turns the moments into finished vertical clips with captions and titles, on the creator's own PC.

SpikeClip 2.1.0 is the first release that runs plugins, and it comes with SDK 1.3.0.

Start building

How a plugin fits in

A plugin is a folder with a manifest, spikeclip.yaml, and a Python script. SpikeClip starts it for each video with a job folder, and every step is optional: a video that uses no plugin is made exactly as before.

  • One plugin can find moments for a video; it replaces SpikeClip's own finding.
  • Up to 3 plugins can understand and up to 3 can rate, after any finder.
  • Up to 3 plugins can suggest edits for the clips that will be made.
  • A plugin's role comes from inputs and outputs in its manifest (Steps).
  • Edit plugins suggest edits that wait for the creator in the editor (Steps).
  • Posting isn't a plugin step: SpikeClip posts clips itself, and through WoopSocial it can post to many sites at once on the creator's own account. kind: publisher is refused: plugins don't post.

What you can build

Someone who knows one game can tell a great moment from a loud one far better than a general-purpose detector. Three kinds of plugin, each with a template to start from:

Game events

Your game shows something when a big play happens: a banner, a line in the kill feed, an icon, a sound. A finder looks for it and hands SpikeClip the moments. Template: game-events, or transcript to find the words the commentary says.

A rater for your community's taste

SpikeClip or another plugin finds the moments; your rater gives each one a new score, by what your viewers like and what they skip. Template: rater.

Notes for better titles

Say what happens in each moment, and SpikeClip's AI uses it when it writes the clip's title, description and hashtags. Template: understander.

Wanted: game events for genres the big clipping apps barely cover, such as fighting games, racing, strategy, card games, MMOs, and retro or emulated games. The Wanted list in Awesome SpikeClip has more ideas nobody has built yet (it is kept in sections.yaml).

Quickstart

Three commands: install the SDK, make a plugin from the game-events template, and run it on a test video the SDK makes. The template is for Quarkbloom Arena, a made-up game; put your own GitHub name, in lower case, in place of your-github-name.

PowerShell (Windows)

py -m pip install "spikeclip-sdk[yaml,test] @ git+https://github.com/ColinGPT9/spikeclip#subdirectory=sdk/python"
py -m spikeclip_sdk new quarkbloom-bursts --template game-events --publisher your-github-name
py -m spikeclip_sdk run quarkbloom-bursts --sample

bash (macOS, Linux)

python -m pip install "spikeclip-sdk[yaml,test] @ git+https://github.com/ColinGPT9/spikeclip#subdirectory=sdk/python"
python -m spikeclip_sdk new quarkbloom-bursts --template game-events --publisher your-github-name
python -m spikeclip_sdk run quarkbloom-bursts --sample

The last command makes a 40-second test video with a red banner and a loud sound, runs the plugin on it the way SpikeClip would, and prints the one moment it finds. You need Python 3.11, the Python SpikeClip runs plugins on; FFmpeg on PATH, for the test video; and Git, because the SDK installs from GitHub. If you use a virtual environment, make it beside your plugin's folder, never inside it.

Building blocks

Modules for the work most game plugins share, in SDK 1.2.0. Each says what it needs, and your plugin's manifest asks for it.

media

Reads the video with the FFmpeg SpikeClip hands over: its size, a part of the screen frame by frame, one frame as a JPEG, its loudness and its scene cuts.

Needs: FFmpeg (the ffmpeg permission), and video.read for the video itself.

signals

Turns numbers and frames into moments: how much of a frame is one colour, how bright it is, loud spikes, stretches of time, and a moment fitted to the clip lengths the creator chose.

Needs nothing of its own: it works on the numbers and frames that media gives it.

text

Finds words in what is said: whole words in any case, with the times they are said, and which ones fall inside a moment.

Needs: the transcript (transcript in inputs and the transcript.read permission).

local_model

Asks the creator's local model in SpikeClip a question, about a frame too when the model can see pictures.

Needs: the ollama permission, and a creator who uses a local model in SpikeClip. It uses that model only on this PC: it refuses when SpikeClip's AI runs at a cloud provider or at an address off this PC, and it ignores proxy settings, so the frames never leave the PC.

testing

Runs your plugin from its own tests, the way SpikeClip would, on the SDK's test video or test transcript.

For tests on your PC, not in the app: install the test extra for pytest.

Free and yours

  • The SDK is MIT (licence). Using it doesn't put your plugin under the AGPL, so your plugin can have any licence; code that new copied from a template keeps the SDK's MIT notice, in TEMPLATE-LICENSE.txt. SpikeClip itself is AGPL-3.0-or-later.
  • Your plugin keeps its own licence, open or closed, and the Marketplace shows it. Your code stays in your own repository.
  • No fee and no share. Listing, updating and installing cost nothing, and SpikeClip takes no share of what you earn. Link your own pricing, sponsors or support page from your manifest.

What creators see

Installing runs nothing: a plugin's code first runs when a video uses it. Before anything is installed, SpikeClip's install screen starts with "This pipeline is a program from the internet. It can do anything you can do on this PC." Then it shows the publisher, the source and commit, the licence, the labels, each permission with whether SpikeClip enforces it or only the developer says so, and a ⚠ line for each kind of data that leaves the PC. Get listed

Creators find plugins in SpikeClip's Marketplace, which reads Awesome SpikeClip, a catalog kept on GitHub. Getting in costs nothing.

  1. Commit your plugin to a public GitHub repository and push it.
  2. From the folder that holds your plugin's folder, write its listing file with listing. It checks that everything is committed and pushed and that your GitHub name owns the repository.
  3. Open one pull request to ColinGPT9/awesome-clips-kitty with that one file. Its check says why if the listing is refused, and the catalog's index is rebuilt after the merge.
  4. Once it is merged, it reaches creators through SpikeClip's online list. In the versions of SpikeClip that have the Marketplace, it shows up the next time the Marketplace checks that list (when it opens, at most once a day), or at once with Check for new pipelines.

PowerShell (Windows)

py -m spikeclip_sdk listing quarkbloom-bursts --section gaming/generic

bash (macOS, Linux)

python -m spikeclip_sdk listing quarkbloom-bursts --section gaming/generic

A listing is for your real plugin: listing refuses one that still has the template's placeholders. Getting listed has the rest.

Questions

Can I name a real game?

Yes, as an unofficial plugin. A listing that names games shows "Unofficial · not made or endorsed by the makers of" those games in the Marketplace. Our own examples use Quarkbloom Arena, a made-up game.

Is a plugin sandboxed?

No. Every plugin runs on the creator's PC with their rights, like any program; SpikeClip doesn't sandbox it. The install screen says what it declares, and which of those SpikeClip enforces.

Which Python do plugins run on?

SpikeClip's own: Python 3.11, with the standard library (except a few modules it leaves out, which validate warns about) and the SDK. SpikeClip can't install other packages yet. Test on 3.11: newer Python syntax or library calls fail there.

Which SpikeClip runs plugins?

SpikeClip 2.1.0 is the first release that runs plugins, and it comes with SDK 1.3.0.

What about edit and posting?

Edit is built, and posting isn't a plugin step. Edit plugins suggest edits that wait for the creator in the editor: cuts, mutes, the volume, fades, the speed, a hook title or a layout. SpikeClip doesn’t put a suggestion into a clip until you use it in the editor and apply your edits (Apply edits, or Apply edits & upload). SpikeClip posts clips itself, and through WoopSocial it can post to many sites at once on the creator's own account. A manifest that asks for a publisher (kind: publisher) is refused: plugins don't post.

Does a rater decide what an automatic channel posts?

Yes, where it posts only the best few clips. When a watched channel or the daily schedule posts only the best few, the scores decide which ones go out, so a rating plugin decides that; elsewhere it decides the order. A moment a rater scores under the creator's minimum score is set aside, unless the creator marked it a must-have.
